# Creative track brief (Adobe / Hacklanta)

Source: user notes for the Creative Section (Adobe-sponsored).

## Main objectives

- New and interesting perspective: user-centric and innovative projects
- Curiosity about the user: encourage curiosity in creative building processes
- Build something unique for the user
- Emphasis on mentorship and collaborative excellence

## Product direction

### AI-assisted project management tool

- Personal tool for tracking project ideas and progress
- Voice recordings for updating task status and archiving records
- User-controlled workflow so creative ownership stays with the user

### User-centric idea generation

- Refuse automated AI suggestions that invent ideas for the user (preserve agency)
- Prompt from historical data and past achievements only
- Facilitate creative thinking via reflective questioning

### Structural breakdown

- Decompose complex projects into distinct parts and features
- Organize features into manageable tasks and technical stacks
- Visualize progress like a detailed notebook

## Feature list

- Minimalist design
- 4-button menu bar
- Deep Thinking AI that accepts audio conversations
- Memory capability
- Organized thoughts/ideas tracking
- Project visualization
- Project decomposition for distinct features
- User authentication
- Sleek modern animation
- Cool tones
- Full-screen shifting gradient bubbles (Gemini-like, full screen)
- Menu bar: shifting gradients distinct from background; translucent with edge shadows
- Users introduce themselves; personalized portfolio and comments about themselves or work
- File processing

## Design constraints (product)

- Cool tones; full-screen bubble gradients
- Translucent menu bar with distinct gradient and edge shadows
- Minimalist; 4-button nav
